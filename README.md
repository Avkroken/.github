# Avkroken/.github

Det här är Avkrokens publika GitHub-organisationsyta.

Repositoryt innehåller endast sådant som ska vara publikt och gemensamt på GitHub:

- organisationsprofil i `profile/README.md`
- community health-filer
- issue-, discussion- och pull request-mallar
- repository-lokal metadataautomation

Applikationskod, intern engineeringkontext och driftinformation hör inte hemma här.
