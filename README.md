# Avkroken/.github

Det här repositoryt är Avkrokens **publika GitHub community/profile-yta**.

Det innehåller endast organisationsprofil och community health-filer som GitHub kan använda för publika repositories. Teknisk organisationskontext och applikationskod ligger i `Avkroken/Avkroken`.

## Här hör hemma

- `profile/README.md`
- `CODE_OF_CONDUCT.md`
- `CONTRIBUTING.md`
- `SECURITY.md`
- `SUPPORT.md`
- issue-, pull request- och discussion-mallar
- `.github/FUNDING.yml`

## Här hör inte hemma

- portalens runtimekod
- interna runbooks eller credentialmodeller
- applikationsspecifik dokumentation
- återanvändbara cross-repository workflows

Portalen för `avkroken.denied.se` finns nu i `Avkroken/Avkroken/apps/portal`.
